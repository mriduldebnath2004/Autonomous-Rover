# Autonomous Rover

Autonomous skid-steer rover built with a Raspberry Pi 4 and Raspberry Pi Pico.

## Features
- LiDAR-based mapping and localization
- Wheel encoder feedback
- IMU heading estimation
- PID motor control
- Autonomous waypoint navigation

## Hardware
- Raspberry Pi 4
- Raspberry Pi Pico (RP2040)
- RPLidar A1
- Magnetic wheel encoders
- IMU
